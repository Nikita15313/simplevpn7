# SimpleVPN 7 3.0.1 — совместимость

Целевая система: Windows 7 SP1 x64 со встроенным .NET Framework 3.5.1. Управляемый код — C# 5, reference assemblies .NET 3.5, mscorlib 2.0; конфигурация допускает CLR4 fallback. Native launcher и официальный Win7 Xray сохранены из проверенной сборки.

- Native launcher SHA256: `890c62647ad7a67dab99a1b423fbab7a0aa12ae63aa5ed8084ab8c5bb530182a`.
- Xray v26.3.27 SHA256: `dd7b2e94fef71c56e34ccef0420d58162c93e2223b1a3dd126db0ddf47d48fdd`.

Сетевой режим — системный HTTP/HTTPS-прокси Windows. Это ограничивает охват приложениями, которые используют системный прокси; TUN и весь UDP не поддерживаются. Прежний прокси восстанавливается при выключении и аварийном завершении. DNS-настройка относится к запросам Xray, исключения напрямую сохраняют обычное разрешение имён.

Ядро выбранного сервера может подготавливаться, пока VPN отключён; системный прокси при этом не включается. Каждое включение требует новой успешной HTTPS-проверки. При выключении прежнее ядро завершается вместе с открытыми соединениями. Вывод ядра удаляется выделенными потоками с ограниченным буфером, чтобы тихие каналы CLR2 не занимали рабочий пул.

Подписки и обновления используют WinHTTP TLS 1.2 с обычной проверкой сертификатов Windows. Исключения проверки сертификатов, изменение хранилища доверия, глобальные TLS-настройки и аналитика не применяются. Публичные обновления запрашиваются без авторизации по фиксированному GitHub API репозитория. Даже ключ прежней версии не передаётся и удаляется из настроек при миграции. Разрешены только ограниченные HTTPS-адреса GitHub, размер и время загрузки ограничены.

Манифест обновления подписывается отдельным RSA-ключом, открытый ключ закреплён в программе. Установщик проверяется по размеру и SHA-256 при загрузке и перед запуском. Фоновая загрузка применяется при очередном запуске приложения; флаг предыдущей попытки защищает от цикла после сбоя. Дистрибутив не содержит GitHub-токенов; публичные релизы загружаются анонимно. Для перехода с 3.0.0 новый установщик требуется запустить один раз вручную, после чего работает обновлённый фоновый канал.

Библиотека конфигураций и настройки защищены CurrentUser DPAPI и ACL каталога данных. Журнал содержит фиксированные идентификаторы событий и агрегированные тайминги, без URL подписки, конфигураций, токенов и вывода ядра. Архив исходников формируется по списку разрешённых типов файлов и не включает каталоги данных, бинарные сборки или приватные ключи.

В этой итерации сборка и проверки выполняются на хосте разработки; реальный CLR2 доступен на нём. Новая версия 3.0.1 не устанавливалась на Samsung, удалённое управление в эту проверку не входит. Работа Google/YouTube в тесте HTTPS означает получение ответа, а не проверку видеовоспроизведения. Доступность конкретного сервера зависит также от провайдера и сети пользователя.
