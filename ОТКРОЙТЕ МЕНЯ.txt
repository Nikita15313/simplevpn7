SimpleVPN 7 • версия 3.0.0

Откройте SimpleVPN7-3.0.0-Setup.exe и установите поверх прежней папки.
Подписки и настройки сохранятся. Если выбрали ZIP, распакуйте всю папку
и откройте SimpleVPN.exe.

«+» — добавить подписку или конфигурации. Источников может быть несколько.
Выберите источник, сервер и нажмите большую кнопку подключения.
В меню доступны удаление подписки и удаление отдельных серверов.
Удалённые серверы можно восстановить. Кнопка обновления получает свежие
серверы и данные трафика от провайдера.

Светлая и тёмная темы находятся в настройках интерфейса.
«—» сворачивает окно в панель задач, «×» оставляет его в трее.
Для завершения выберите «Выход» у значка рядом с часами.

Обновления приложения: в настройках один раз добавьте отдельный ключ GitHub
для приватного репозитория SimpleVPN7 с разрешением Contents: read.
После этого новые версии загружаются в фоне и устанавливаются при следующем
запуске приложения. Windows перезагружать не требуется.

Windows 7 SP1 x64; компонент .NET Framework 3.5.1. Ядро Xray уже в комплекте.
Подключение использует системный HTTP/HTTPS-прокси для браузеров
и приложений, которые его учитывают.
