# Проверки SimpleVPN 7 3.0.1

Проверка выполняется 16 ноября 2026 года на хосте разработки с доступным CLR 2.0.50727.9188. Приложение компилируется против настоящих .NET 3.5 reference assemblies. Новая версия не устанавливалась на Samsung; скорость подключения и воспроизведение видео на нём в этой итерации не измерялись.

Подтверждены отдельные группы проверок:

- 46 проверок библиотеки источников: миграция прежней подписки, добавление и переключение источников, удаление, скрытые серверы и восстановление.
- 11 проверок отображения и импорта данных: двоичные единицы трафика, округление срока, неизвестные значения, число конфигураций, BOM и пределы размера файла.
- 20 проверок XHTTP extra: вложенные параметры соединения, допустимые конфигурации и отклонение непригодных значений.
- 44 проверки параметров подключения и шесть конфигураций настоящего ядра.
- 18 проверок обновлений: подпись манифеста, размер/хеш установщика, фиксированный URL репозитория, анонимный режим и удаление прежнего сохранённого ключа GitHub.
- 41 проверка транспорта обновлений: доверенные адреса, снятие токена при редиректе, запрет чужих/локальных адресов и недопустимых аргументов.
- 8 проверок отложенного обновления: выключенная автоматика, отсутствующие/повреждённые данные, недоверенная подпись, сохранение обычного запуска.
- Канал SimpleVPN7 теперь публичный. Запросы обновлённого приложения выполняются без Authorization; сохранённый ключ прежней версии очищается при миграции.

Итоговый полный прогон версии 3.0.1 прошёл на CLR2: все перечисленные группы и прежние проверки сетевого ядра, восстановления, активации, диагностики, подготовки и очистки процессов. ## Проверка текущей подписки

Ответ провайдера содержал 13 конфигураций. Теперь разобраны все 13: прежний разборщик пропускал часть профилей из-за параметров XHTTP extra, поэтому один видимый сервер не означал недоступность остальных.

На хосте разработки через настоящее ядро получены успешные ответы Google и проверки соединения для 13 из 13 профилей. YouTube также ответил для всех 13 с учётом повторной проверки одного немецкого профиля с пределом десять секунд после первого тайм-аута в шесть секунд. Это подтверждение HTTPS-ответа, без проверки видеовоспроизведения и без обещания постоянной доступности сервера. Все 13 тестовых ядер остановлены, системный прокси не изменён.

## Дистрибутив и обновления

Установщик собирается из девяти разрешённых файлов, затем извлекается и сверяется с подготовленным каталогом по SHA-256. Native launcher и официальный Xray сохраняются без изменений. Архив исходников составляется по разрешённым типам файлов. Данные подписки, токены, приватный ключ подписи и вспомогательные диагностические программы в дистрибутивы не входят.

После публикации публичного релиза без ключа отдельно проверяются получение манифеста и подписи, загрузка установщика и его хеш. Такая проверка не запускает установщик и не изменяет настройки Windows; её результат записывается в отчёт выпуска вне уже собранного установщика.
