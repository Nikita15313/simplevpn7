# SimpleVPN 7 — 3.0.1

Приложение для Windows 7 SP1 x64: большая кнопка подключения, список серверов, подписки и светлая/тёмная тема. Это самостоятельная программа с интерфейсом по образцу Happ.

## Установка и работа

Откройте `SimpleVPN7-3.0.1-Setup.exe` и установите поверх прежней папки. Подписки и настройки сохраняются. Для переносимой сборки распакуйте ZIP целиком и запустите корневой `SimpleVPN.exe`. Включённого компонента Windows .NET Framework 3.5.1 достаточно; Xray уже в комплекте.

Кнопка «+» добавляет URL-подписку, отдельные ссылки конфигураций или JSON. Можно хранить несколько источников и переключаться между ними. Старая подписка переносится в библиотеку автоматически. Удаление источника и отдельных серверов доступно в интерфейсе; скрытые серверы не возвращаются при обновлении подписки до команды восстановления. Секретные ссылки и конфигурации хранятся через DPAPI текущего пользователя.

Данные трафика и срока берутся из ответа провайдера. Гигабайты отображаются с делителем 1024, неполный оставшийся день округляется вверх. При открытии приложения обновляются данные старше пяти минут; ручная кнопка обновления запрашивает данные снова. Неизвестный лимит или срок не подменяется нулём. Разница между устройствами всё ещё возможна, если провайдер отдаёт разные или закэшированные ответы.

Проверка серверов выполняет настоящий HTTPS-запрос через каждый профиль. Можно сортировать список по задержке и выбирать сервер самостоятельно. «—» сворачивает окно в панель задач, «×» оставляет приложение в трее, «Выход» завершает подключение.

## Автоматические обновления

Обновления доступны из публичного репозитория `Nikita15313/simplevpn7`. Приложение получает их без входа в GitHub и без ключей доступа. Подписки, серверные учётные данные и настройки остаются в локальном защищённом каталоге и в репозиторий не отправляются.

С версии 3.0.0 необходимо один раз установить `SimpleVPN7-3.0.1-Setup.exe` поверх текущей папки: прежний проверщик требовал ключ к приватному каналу. После этого включённые автоматические обновления проверяются при запуске и каждые шесть часов, новая версия скачивается в фоне и устанавливается при очередном запуске приложения. Подписки и настройки сохраняются, Windows не перезагружается. Старый сохранённый ключ GitHub очищается при миграции и для запросов не используется.

Подпись RSA/SHA-256 проверяет происхождение манифеста, SHA-256 — содержимое установщика. Размер и хеш повторно проверяются перед установкой. Повреждённая загрузка не запускается, неудачная попытка не создаёт бесконечного цикла обновлений. При временной недоступности GitHub текущая версия продолжает работать.

## Совместимость и проверка

Используется системный HTTP/HTTPS-прокси Windows. Подключение обслуживает браузеры и приложения, которые учитывают этот прокси. TUN, перехват всего UDP и изменение DNS Windows в сборку не входят. Маршрутизация и выбор DNS применяются внутри Xray.

Код компилируется как C# 5 против настоящих reference assemblies .NET 3.5. Тесты этой версии выполняются на хосте разработки; установка 3.0.1 на Samsung и просмотр видео на нём в этой проверке не выполнялись. Подробности — в `TEST-RESULTS.md` и `COMPATIBILITY.md`.

`build.ps1` собирает приложение, `tests.ps1` запускает проверки. `package.ps1` пересобирает native launcher при наличии Visual C++/Windows SDK; готовый релиз может повторно использовать проверенные native-байты. Подписки, приватный ключ подписи и персональные данные в архив исходников не включаются.
